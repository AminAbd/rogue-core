ROGUE CORE

Offline
How to play
  • 1 to 8 people, each on their own phone. Computer players fill the table up to 3, and the host can add more. Talking, bluffing and accusing happen out loud.
  • Everyone is secretly a Sysadmin or a Rogue AI. Press and hold your secret panel to see your team.
  • Each round everyone gets face-down cables: Clean keys, Dead cables and one Rogue core somewhere. You see only how many of each you hold, not which is which.
  • The player with the cutter taps someone else's cable to cut it. Whoever was cut takes the cutter next.
  • Each round has one cut per player. Then the uncut cables are reshuffled and dealt again, one fewer each. There are 3 rounds.
  • Sysadmins win when every clean key is found. Rogue AIs win if the rogue core is cut, or if 3 rounds pass first.

Phones connect directly to each other. It works best when everyone is on the same Wi-Fi.
